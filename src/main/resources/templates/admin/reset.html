Reset da Aplicação (Admin)

Restauração de Dados

Esta funcionalidade é exclusiva para administradores. Ela restaura o banco de dados da aplicação para a configuração inicial de fábrica.

O que acontecerá:
  • Todas as vendas, caixas e movimentações serão excluídos.
  • Os produtos e categorias de demonstração serão reinseridos.
  • Os usuários padrão (admin / operador) serão redefinidos.
