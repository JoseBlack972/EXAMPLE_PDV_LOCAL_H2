Guia Whitelabel & Manual de Deploy Corporativo

Instruções completas para personalizar a marca da sua empresa, migrar o banco de dados para PostgreSQL/MySQL e subir em produção.

Configurar Minha Empresa
1. Como Personalizar o Sistema (Whitelabel) para sua Empresa

Este software foi arquitetado como uma plataforma Whitelabel, permitindo que qualquer empresa ou Software House o implemente com sua própria identidade visual e dados fiscais:

  • Identidade da Empresa no Cupom Fiscal e Telas: Acesse o menu Admin → Configuração da Empresa para cadastrar Razão Social, Nome Fantasia, CNPJ, Inscrição Estadual, Telefone e Endereço. Todos os dados são refletidos instantaneamente nos cupons fiscais emitidos por todos os operadores.
  • Cores e Identidade Visual: No arquivo src/main/resources/static/css/style.css, você pode alterar as variáveis de cor primária na raiz (:root): 
    :root {
    --primary-color: #0d6efd; /* Altere para a cor primária da sua marca */
    --success-color: #198754;
    --danger-color: #dc3545;
}
  • Logotipo e Ícones PWA: Substitua o nome e o ícone do sistema no src/main/resources/templates/fragments/layout.html e os ícones em manifest.json.
2. Migração do Banco de Dados para Produção (PostgreSQL / MySQL)

Por padrão, a aplicação utiliza o banco H2 em arquivo para facilitar testes rápidos e desenvolvimento sem dependências externas. Para ambientes de produção corporativa com múltiplos caixas simultâneos, a migração para PostgreSQL ou MySQL é altamente recomendada:

Opção A: Migração para PostgreSQL (Recomendado)

1. Adicione o driver PostgreSQL no pom.xml:

<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>

2. Atualize o docker-compose.yml com o container oficial do PostgreSQL:

services:
  app:
    build: .
    ports:
      - "8080:8080"
    environment:
      - SPRING_DATASOURCE_URL=jdbc:postgresql://postgres-db:5432/pdvdb
      - SPRING_DATASOURCE_USERNAME=pdv_user
      - SPRING_DATASOURCE_PASSWORD=pdv_secret_pass
      - SPRING_JPA_HIBERNATE_DDL_AUTO=update
    depends_on:
      - postgres-db

  postgres-db:
    image: postgres:16-alpine
    restart: always
    environment:
      - POSTGRES_DB=pdvdb
      - POSTGRES_USER=pdv_user
      - POSTGRES_PASSWORD=pdv_secret_pass
    volumes:
      - pgdata:/var/lib/postgresql/data
    ports:
      - "5432:5432"

volumes:
  pgdata:
Opção B: Migração para MySQL / MariaDB

Adicione a dependência com.mysql:mysql-connector-j e aponte a URL para jdbc:mysql://mysql-db:3306/pdvdb?useSSL=false&serverTimezone=America/Sao_Paulo.

3. Certificados Digitais (A1 / A3) e Código CSC da SEFAZ

Para emissão real de NFC-e com valor fiscal perante a Secretaria da Fazenda Estadual:

  • Certificado Digital A1 (.pfx): É o padrão mais estável para sistemas web e PDVs em rede. Copie o arquivo do certificado para uma pasta segura no servidor (ex: ./certificados/empresa.pfx) e monte como volume no Docker.
  • Token A3: Funciona em terminais desktop locais instalando a cadeia de certificados e o driver PKCS#11 da leitora de cartão ou token USB.
  • Código de Segurança do Contribuinte (CSC): Acesse o portal da SEFAZ do seu estado (ex: SEFAZ SP, SEFAZ MG, SEFAZ PR), faça login com o Certificado Digital da empresa e solicite o ID do CSC e o Código CSC de Produção/Homologação. Cadastre esses valores no menu da empresa.
4. Comandos Essenciais para Manutenção e Execução
Comando Finalidade
docker compose up --build -d Constrói a imagem com as últimas alterações e inicia em background.
docker compose logs -f app Acompanha em tempo real os logs de execução e transações da aplicação.
docker compose down Interrompe e encerra os containers mantendo os volumes de dados salvos.
docker compose restart app Reinicia o serviço da aplicação sem derrubar o banco de dados.
